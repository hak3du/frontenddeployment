04 / WHAT EACH LAYER DOES

Four layers.
Clear roles.

The design separates key derivation, post-quantum operations, authenticated encryption and verification. This makes it possible to identify what is implemented, what remains experimental and what evidence is still needed.

LAYER / 01

Derivation & entropy

KDF · INPUT VALIDATION · KEY LIFECYCLE

Define how material is derived, which entropy sources are trusted, and how parameters and key lifetimes are controlled.

LAYER / 02

Post-quantum components

ML-KEM · SIGNATURES · LIBOQS

Specify the selected primitive and parameter set. Keep encapsulation, signatures and hybrid composition distinct.

LAYER / 03

Authenticated protection

AES-GCM · AEAD · NONCE DISCIPLINE

Protect payload confidentiality and integrity with correct nonce handling, key separation and authenticated context.

LAYER / 04

Verification & evidence

TEST VECTORS · TAMPER TESTS · BENCHMARKS

Measure the implementation, exercise failure paths and publish reproducible results that can be independently reviewed.

06 / HOW THE RESEARCH IS EVALUATED

Measure it.
Then make claims.

AHE should be judged by reproducible evidence: correctness tests, tamper tests, performance measurements, dependency review and independent cryptographic analysis.

01 / THREAT MODEL

Define the adversary.

Document assets, trust boundaries, attacker capabilities, assumptions and the security properties each component is intended to provide.

02 / MEASUREMENT

Benchmark the build.

Measure latency, throughput, memory, key and ciphertext sizes, entropy characteristics and failure behaviour against reproducible baselines.

03 / ASSURANCE

Make review possible.

Publish implementation details, test vectors, dependency versions, known limitations and evidence for external evaluation.

RESEARCH STATUS
IMPORTANT DISTINCTION

AHE is experimental research, not an established cryptographic standard or independently validated security product. The architecture shown is a conceptual workflow; only components demonstrated in source code and test results should be treated as implemented. Combining cryptographic layers does not automatically increase security.
